#  RP Unavagam – Restaurant Landing Page

## About the Project

Spice Garden is a modern and responsive restaurant landing page developed using HTML5 and CSS3.

The website is designed to showcase restaurant information, popular food items, and contact details through a clean and attractive user interface.

## Technologies Used

- HTML5
- CSS3

## Features

- Modern white and orange design.
- Responsive navigation bar.
- Attractive hero section.
- About section.
- Popular dishes with food images.
- Contact information section.
- Footer with social media links.
- Hover effects and responsive layout.

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in your web browser.

# Personal Portfolio Website

## About the Project

This is my personal portfolio website, created to showcase my profile, education, technical skills, projects, experience, and activities.

The website uses a modern design with glassmorphism and interactive visual elements to present my learning journey and development work.

## Features

- Home section with personal introduction
- About Me section
- Education details
- Technical Skills
- Projects showcase
- Experience and Activities
- Contact section
- Resume download option
- Responsive website design
- Interactive visual elements

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Interactive functionality |
